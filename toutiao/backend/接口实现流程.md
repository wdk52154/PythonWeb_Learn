# 接口实现流程

每个新接口按四步落地：**模块化路由 → 定义模型类 → 数据库 CRUD → 路由调用逻辑**。

## 1. 模块化路由

- 定义 `APIRouter` 实例（`prefix` 路由前缀、`tags` 分组标签，参照 API 接口规范文档）
- 在 `main.py` 中注册路由：`app.include_router()`

```python
# routes/news.py
router = APIRouter(prefix="/api/news", tags=["news"])

# main.py
app.include_router(news.router)
```

## 2. 定义模型类

参照**数据库表**结构定义 ORM 模型类（表名、字段、类型、约束一一对应）：

```python
# models/news.py
class Base(DeclarativeBase):
    created_at: Mapped[datetime] = mapped_column(DateTime, default=datetime.now)
    updated_at: Mapped[datetime] = mapped_column(DateTime, default=datetime.now, onupdate=datetime.now)

class Category(Base):
    __tablename__ = "news_category"
    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    name: Mapped[str] = mapped_column(String(50), unique=True, nullable=False)
    sort_order: Mapped[int] = mapped_column(Integer, default=0, nullable=False)
```

## 3. 数据库 CRUD

在 `crud/` 目录封装操作数据库的方法，路由不直接写 SQL：

- 查询：`select(模型类)` + `where / offset / limit`
- 新增：`db.add()` → `commit()` → `refresh()`
- 更新：查出对象改属性 → `commit()`
- 删除：`delete()` → `commit()`

```python
# crud/news.py
async def get_categories(db: AsyncSession, skip: int = 0, limit: int = 100):
    stmt = select(Category).offset(skip).limit(limit)
    result = await db.execute(stmt)
    return result.scalars().all()
```

## 4. 路由调用逻辑

- `Depends` 注入数据库会话依赖（`get_db`）
- 调用 crud 封装好的查询逻辑
- 统一格式响应结果（`code / message / data`）

```python
# routes/news.py
@router.get("/categories")
async def get_categories(
    skip: int = 0, limit: int = 100, db: AsyncSession = Depends(get_db)
):
    categories = await news.get_categories(db, skip, limit)
    return {"code": 200, "message": "获取新闻分类成功", "data": categories}
```

（`routes/users.py` 里已演进为 `success_response(message=..., data=...)` 统一封装，效果相同。）

## 调用链路总结

```
请求 → 路由层(routes/) → crud层(crud/) → 模型层(models/) → 数据库
     ← 统一响应(code/message/data) ← 查询结果 ← ORM对象 ←
```

分层职责：路由层只管参数校验和响应组装，crud 层只管数据库读写，模型层只管表结构映射——改任何一层不影响其他层。
